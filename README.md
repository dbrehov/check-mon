Altcoin Price Analyzer project for analyzing cryptocurrency trends.

## Использование
Запуск проекта через терминал:
`npx ts-node src/run.ts [параметр]`

### Параметры запуска:
- (без параметров) — Проверка публичного IP и отправка скриншота в Telegram.
- `cookie` — Авторизация в Google и сохранение куки в файл `cookies.json`.
- `colab` — Автоматический запуск ноутбука в Google Colab (видимый режим).
- `colab less` — Автоматический запуск ноутбука в Google Colab (скрытый режим).
